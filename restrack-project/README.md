# restrack-project/ — مركز مشروع منصة ريستراك الجديدة

كل ما يخص تطوير المنصة الجديدة (تخطيط + تصميم + أصول) في مكان واحد.
كود التطبيق نفسه يبقى في بنية Laravel (`app/`, `resources/`, `routes/`, `config/`, `database/`).

```
restrack-project/
├── plan/
│   ├── MASTER_PLAN.md     ← الخطة الكاملة (استراتيجية، ميزات، أدوار، أمن، امتثال، تصميم)
│   └── ROADMAP.md         ← سجل العمل التكتيكي + جدول المستويات + النصوص الحرفية
├── design/
│   ├── DESIGN-SYSTEM.md   ← نظام التصميم (Vibrant Premium + زجاجي فاخر + ليلي/نهاري)
│   ├── mockups/
│   │   ├── 01-vision-classic.html    ← الرؤية الكلاسيكية (كحلي/ذهبي)
│   │   ├── 02-vibe-directions.html   ← لوحة اختيار الروح (①②③) — اختير ①
│   │   └── 03-premium-glass.html     ← ★ الاتجاه المعتمد: زجاجي فاخر بأيقونات SVG
│   └── icons/            ← أيقونات SVG فاخرة (مضمّنة في المشغّل النهائي)
└── assets/              ← صور/لوقو يزوّدنا بها المالك (خلفية الهيرو، شعارات الـ guidelines)
```

## الحوكمة (تبقى في جذر المستودع لأنها تُحمَّل تلقائياً)
- **`/CLAUDE.md`** — الدستور (قواعد كيفية العمل، Definition of Done، ألغام الانحدار).
- **`/.claude/agents/regression-verifier.md`** — وكيل التحقق الصارم بعد كل تعديل.

## الاتجاه المعتمد
**① Vibrant Premium — تنفيذ زجاجي فاخر:** شبابي واحترافي وفخم (ليس طفولياً)، أيقونات SVG راقية بدل الإيموجي،
glassmorphism قوي يتفوّق على «Liquid Glass»، وأنيميشن «واو» خفيف على الأداء. كحلي `#16264b` + ذهبي `#af9136`
+ نبضات بنفسجي `#7C6CFC` / تركوازي `#10B4A0`. مود ليلي ونهاري. عربي RTL أولاً.

## أين نقف
- ✅ الدستور + وكيل التحقق + الخطة + سجل العمل.
- ✅ أساس رموز التصميم في `resources/css/app.css` (ألوان نابضة + ليلي/نهاري) — يُبنى بنجاح.
- ⏭️ تطبيق التصميم الزجاجي على الواجهات الفعلية (يبدأ بالصفحة الرئيسية).
- ⏳ بانتظار: PHP 8.2 + `composer install` (للخلفية)، وصور الهيرو/اللوقو من المالك.
